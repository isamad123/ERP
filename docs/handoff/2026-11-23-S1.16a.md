## API contract (both halves build against this; JSON camelCase)
Permissions: `itg.imports.manage` (use the centre; every type also needs its own permission, `canRun` says), `itg.imports.design` (template designer).
- `GET /api/itg/imports/types` -> `[{code, module, name{lang}, permission, canUpdate, canRun, columns:[{name, field, type(text|number|date|bool|option), required, label{lang}, lookup|null, options[]|null, example|null}]}]`
- `GET /api/itg/imports/templates?type=` -> `[{id, code, name{lang}, entityType, format(csv|xlsx), mode(create|create_or_update), isDefault, version, isActive, rowVersion, mapping}]`
  `mapping = {delimiter: ","|";"|null, sheet: string|null, headerRow: 1, columns:[{field, source (file column header), transform:[trim|upper|lower|date:<fmt>|number:<culture>], default: string|null}]}`
- `POST /api/itg/imports/templates` `{code, name{lang}, entityType, format, mode, mapping}` -> 201 template (designers only); `PUT /api/itg/imports/templates/{id}` `{name, mode, mapping, rowVersion}` -> 200, version +1.
- `GET /api/itg/imports/templates/{id}/file?format=csv|xlsx` -> the template file (headers, one example row, a sheet or section of allowed values).
- `POST /api/itg/imports/templates/{id}/test` (multipart `file`) -> `{totalRows, errorRows, errors:[{rowNo, field, message}] (first 100), sample:[{rowNo, values{}}] (first 5 mapped rows)}`; nothing is stored or saved.
- `POST /api/itg/imports/batches` (multipart `file`, `templateId`) -> 201 batch; refused: infected (`errors.import.infected`), too big or too many rows (`errors.import.too_large`, `errors.import.too_many_rows`), wrong type (`errors.import.unsupported_file`), no permission for the type.
- `POST /api/itg/imports/batches/{id}/validate` -> 202 batch (status `validating`, runs as a job); `POST .../commit` -> 202 (only from `validated` with `errorRows = 0` or when the template allows skipping: rows with errors are never written; commit writes the good rows only after `okRows > 0`); `POST .../rollback` `{reason}` -> 200 or 409 with `errors.import.rollback_*` key.
- `GET /api/itg/imports/batches?type=&status=` -> `{items:[batch], next}`; `GET .../batches/{id}` -> batch.
  `batch = {id, templateId, templateName{}, entityType, fileName, status(uploaded|validating|validated|committing|committed|failed|rolled_back), mode, totalRows, okRows, errorRows, createdRows, updatedRows, progressPct, jobRunId, createdAt, createdBy, validatedAt, committedAt, rolledBackAt, canCommit, canRollback, rollbackBlockedKey|null}`
- `GET .../batches/{id}/errors?limit=100&cursor=` -> `{items:[{rowNo, field|null, message, phase}], next}`; `GET .../batches/{id}/errors.csv` -> file: original row plus a `message` column.

## Server notes (server fork, Sonnet 5.5)
Built and tested on a real PostgreSQL: generated `ImportWriter` per table (`CSharpEmitter.ImportWriter`, registered by `AddKernelImportWriters`), `ImportManifest`/`ImportCatalog`/`ImportSetup` (`imports.json`, default template `default.<type>`), `ImportFiles` (store, scan, encrypt), `ImportRowPipeline` (map, transform, lookups, key check, writer inside a savepoint), `ImportService`, `ImportValidateJob`, `ImportCommitJob`, `ImportEndpoints` under `/api/itg/imports`, writers `users` and `org_units`, settings `itg.import.rollback_days` and `itg.import.max_rows`.
Contract shapes are as written above. Differences the web should know: a commit with problem rows needs `{"skipErrors": true}`, else 409 `errors.import.has_errors`; a mapping's `field` may be the type column's `name` (preferred) or its `field`; `GET /batches` shows a person's own batches, and everyone's to holders of `itg.import_batches.read`; the template test returns `sample[].values` keyed by the write request's property names; refusal bodies are problem details whose `title` is the `errors.import.*` key and `detail` carries a short hint (the missing header names, the mapping problems).
Tests: `tests/Erp.IntegrationTests/ImportCentre` (`ImportTests`, `ImportTypeTests`, `ImportScaleTests`; the scale test reads `IMPORT_SCALE_ROWS`, default 50,000) and `tests/Erp.UnitTests/Itg/ImportUnitTests.cs`.
