Model: Sonnet 5.5, medium effort (slice Model line, part a). Lane A (CR-082). Standing ruling CR-083: every recommendation is the ruling.

## Built (3 lines)
Server side of the first-run wizard and checklist: each module declares wizard steps and readiness items in `setup-tasks.json` (kernel's is embedded), seeded into `cfg.setup_tasks` by `migrate`, provisioning and licence changes (`SetupTaskSetup`), per company when a checklist opens.
`IReadinessCheck` (module code, kernel runs it): seven kernel checks (company profile, location, units, holiday calendar of the year, numbering per document type, approval routes per licensed type, a second administrator). Checks run whenever the checklist opens and decide their items; manual items and steps are ticked, skipped (steps only) and re-opened through `/api/cfg/readiness`.
Go-live per module and company: refused while a required item is open unless a reason (1 to 500 characters) is given; stored in `cfg.setup_tasks.note`, in the change log; `IGoLiveGate` lets a module ask (payroll finalization, S1.38). Nothing else is blocked (ruling Q4).
