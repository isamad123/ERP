## Built
An employee who forgot to punch (or HR or a manager for them) asks for a correction from the exception queue or a date, with the time in or out and a reason. The line manager (HR Admin when there is none)
approves in the shared inbox; nobody approves their own request or one made for them. Approval writes a correction punch (source `regularization`; it supersedes the person's own punch when there is one, the
original stays) in the same transaction and re-queues only that day: the day becomes present and the exception `regularized`. A rejection changes nothing. Duty requests (on duty, official visit, work from home,
field duty) for whole days or hours work the same way; on approval the engine reads them, and each kind's "counts as present" is a flag in the `attendance` policy (work from home off until set). A date in a locked period
is refused. The exception queue filters by unit, kind, status and age; screens `/time/exceptions` and `/time/requests` (English and Urdu).
