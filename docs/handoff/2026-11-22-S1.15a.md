## Built (3 lines)

Public `GET /api/kernel/branding` and `/logo` (anonymous, tenant from the host, only name, logo, banner and terms) read the six new `cfg.branding.*` settings and the logo file (attachment owner `cfg.branding`); the sign-in frame and top bar show them.
`iam.*` keys and number formats are edited in the same screen ("Sign-in and security" group) through the existing `PUT /api/cfg/settings/{key}`, which hands `iam.*` to the access settings service.

## Found while building
- Settings with `layers: [tenant]` (idle timeout, password rules) cannot be overridden per company; the drawer offers only the layers the definition allows (the browser test uses the time zone for the company override).
- React Aria's number field clamps to its range silently, so the editor leaves the range to the server and the field error.
- The browser test host had no file store; it now has a folder store and a scanner that finds nothing.
