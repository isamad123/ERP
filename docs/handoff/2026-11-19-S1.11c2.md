# Handoff: S1.11c2 templates and PDF (slice S1.11 Build item 20)

- **Done:**
  - **Templates (KRN-DOC-05):** `Erp.Kernel.Infrastructure/Documents/Templates/TemplateService.cs` (`/api/doc/templates`, `Erp.Kernel.Api/Documents/TemplateEndpoints.cs`): create (first draft version), new draft, change draft, activate (the active version becomes retired), retire, preview against sample data, produce a document for a record, list of generated documents of a record. The active version is never changed. A body is checked on save: size (`doc.template.max_kb`), format, Scriban syntax, and every name it uses must be a declared field of the record type (tried against invented sample values in strict mode). One draft at a time; row versions guard against stale edits.
  - **Sandbox:** `TemplateSandbox.cs` (Scriban 7.6.1): no include or file access, no .NET objects, the machine clock removed (`now` and `today` come from the injected clock), limits on loops, recursion, output and time. Supplied text is HTML-encoded for HTML and PDF output. `qr` (QRCoder, SVG) and `barcode` (own Code 128 set B encoder, `Code128.cs`, table checked against a reference encoding) are available in templates.
  - **PDF (Q17):** `ChromiumPdfRenderer.cs` drives the server's Chromium with PuppeteerSharp; no script, every non-data request refused, content policy on the page; page limit `doc.pdf.max_pages`. Fonts (Noto Sans, Noto Nastaliq Urdu, OFL 1.1) are embedded resources (`Documents/Templates/Fonts`), `DocumentFonts.cs`; Urdu pages are `dir=rtl`.
  - **Letterhead:** a `part` template with code `letterhead` per company and language (the company's own preferred over the all-companies one); its text wraps the letter at `{{ content }}`.
  - **Generated documents:** a PDF is stored through `IAttachmentService.UploadAsync` (so it is encrypted, scanned, sized, versioned, kept and held by the c1 rules) and recorded in `doc.generated_documents`. Other output formats are returned, not stored (CR-055 (6)).
  - **Salary (Q26, HRM-DOC-08):** a template that uses salary-class fields needs the new permission `doc.templates.generate_salary`; each generation using sensitive fields is written to `aud.access_log` (action `print`) before the document leaves the server; the file is marked sensitive.
  - **Batch (Q27):** job `kernel.doc_generate_batch` (`GenerateBatchJob.cs`, manual, runs as the requester, parameters `templateId` and `ownerIds`, never retried).
- **Data design:** `V202611152608__kernel__design_s1_11c_r3.sql` (generator key `S1.11c-r3`): `doc.templates.kind` accepts `part`. Generated writes of `doc.templates`, `doc.template_versions` and `doc.generated_documents` are closed (`api_actions: [read]`); the write permission codes are hand-written in `TemplatePermissions`. **CR-055 is Proposed**: the product owner confirms it with the slice report.
- **Settings:** `doc.template.max_kb`, `doc.pdf.max_pages`. **Host settings:** `Pdf:ChromiumPath`, `Pdf:NoSandbox`, `Pdf:TimeoutSeconds`, `Pdf:Parallel` (`docs/runbooks/pdf-rendering.md`). Registration: `AddKernelDocuments(setting)` also registers the renderer and the service, so both hosts get them.
- **Tests:** unit `tests/Erp.UnitTests/Documents/TemplateSandboxTests.cs` (11), `GenerateBatchJobTests.cs` (3); integration `tests/Erp.IntegrationTests/Documents/TemplateTests.cs` (10, real PostgreSQL, real Chromium; the test host sets `Pdf` options with `NoSandbox`); isolation probe `Tenancy/Isolation/TemplateProbe.cs`.
- **For S1.24, S1.25, S1.35 (modules that print):** register `ITemplateDataProvider` (entity type = table name, `Fields` with class general, personal or salary, `LoadAsync` returns null for a record the caller may not read and applies the module's data scopes) and an `IAttachmentOwner` for the same type. Pack templates (letters, payslips, bank files) are rows with `source = 'pack'` seeded by the module; their bodies are Scriban text. Password-protected PDFs come with HRM-PAY-28 (`is_password_protected` is always false today).
- **For S1.15 (screens):** template editor screen over these endpoints (draft, preview, activate); the list and detail are the generated read endpoints.
- **Open:**
  - Chromium must be installed on every API and worker server (runbook). Not tested here: a Chromium that refuses to start (the 503 path is covered by code only).
  - `xlsx` and Word are not built (Q19). Non-PDF outputs are not stored.
  - A field name that only looks like a salary field inside `{{ }}` counts as used (errs towards the salary right); loop variables are matched by leaf name for list fields.
  - Urdu texts in `documents.ur.json` and the new settings need a native speaker's review.
