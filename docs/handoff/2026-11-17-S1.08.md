# Handoff: S1.08 numbering (gap-free and gap-allowed)

- **Done:**
  - One kernel service gives every document number: `Erp.Kernel.Contracts.Numbering.INumberAllocator`, implemented by
    `Erp.Kernel.Infrastructure/Numbering/NumberAllocator.cs`. Scheme: the document's branch first, else company-wide,
    else (no scheme of that type at all) the default scheme, created on first use and change-logged as the system (Q6, Q7).
    Period from the business date, else today in the company's time zone (`org.time_zone`, P3).
  - Gap-allowed: a PostgreSQL sequence per series and period (`cfg.numseq_<series>_<period>`, cache 1), taken on its own
    short connection; never waits, never rolled back. Gap-free: the counter row in `cfg.numbering_counters` is advanced in
    the caller's transaction (`AssignAsync(request, transaction)`), lock wait limit 5 seconds (`errors.numbering.busy`).
  - Pattern rules (`Erp.Kernel.Domain/Numbering/NumberPattern.cs`, also compiled into the generator): `{seq:N}`, `{yyyy}`,
    `{yy}`, `{mm}`, `{fy}`, `{company}`, `{branch}`; reset rules never, yearly, monthly, fiscal_yearly (company setting
    `cfg.numbering.fiscal_year_start_month`, country default from `Numbering/country-defaults.json`, P4).
  - Scheme services (`NumberingAdministrationService`): create, edit only before first use (row locked first), retire;
    continuation of a retired pattern keeps reset, gap-free and start value (P1); branch schemes need `{branch}` (P2).
    The series of identical-pattern schemes belongs to the member that issued numbers (`cfg.numbering_series_root`).
  - Manual numbers (HRM-EMP-04): `CheckManualAsync` refuses a number the scheme could still produce.
  - Voids: `INumberVoids.RecordAsync` (in the cancel's transaction), one per number; void report per scheme and range.
  - Endpoints: `POST /api/cfg/numbering/schemes`, `PUT /api/cfg/numbering/schemes/{id}`, `POST .../{id}/retire`,
    `GET /api/cfg/numbering/document-types?companyId=`, `GET /api/cfg/numbering/void-report?schemeId=&from=&to=`.
    Permissions `cfg.numbering_schemes.create/update/retire` (hand-written, `NumberingPermissions`) and
    `cfg.numbering.void_report` (Company Admin, Auditor; Tenant Admin through `cfg.*`). Texts
    `Erp.Kernel.Contracts/Numbering/Localization/numbering.{en,ur}.json`.
  - Provisioning and `migrate` seed settings and default schemes (`NumberingSetup`, not change-logged, like baseline roles).
- **Data design and generator (CR-033, CR-035):** key `numbering:` on nine HR tables (makes the column read-only; the
  generated create calls `AssignOnCreateAsync`); generated `HrmNumberingTypes.g.cs` and `Access/numbering.g.json`; keys
  `optional_added_in`, `enum_added_in`, `checks_added_in`, `uniques_added_in`. Migrations
