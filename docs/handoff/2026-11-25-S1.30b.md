# 2026-11-25 S1.30b live dashboard, standard attendance reports, manager view, proof files, browser scenarios (Build items 5 to 8, R-161, R-162)

## Built
HR and managers see today's attendance live: present (of which late), absent, on leave, on duty, not yet punched, not due, not scheduled, no policy, by unit and location, with the people behind each
count; the screen asks again every `hrm.att.dashboard_refresh_seconds` (60). A manager sees only their team. Seven standard reports (daily and monthly muster, absenteeism, late and early, punch log,
device sync, exception ageing) read database views `hrm.rpt_att_*` with the data scope applied, no pay or salary field, each exportable through the export centre. Proof files can be added to
regularization and duty requests (owners, file ids kept at decision). Screens `/time/dashboard`, `/time/reports`, `/time/team` and proof upload in the request forms, English and Urdu.
