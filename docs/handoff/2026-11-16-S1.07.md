# Handoff: S1.07 audit log, hash chain, access log, per-person keys

- **Done:**
  - Change log for every EF Core write (`Audit/ChangeAuditInterceptor.cs`): create, update with field-level before/after,
    soft delete, status change; written through `aud.append_changes` in the same transaction just before commit (the
    interceptor opens a transaction when the caller has none). Actor, actor kind, source (`ui` for signed-in web users,
    `system` otherwise), correlation id (`X-Correlation-Id` answer header), client address, company.
  - Hand-written services: every `iam.*` event (identity, access, settings, platform recovery) also writes a security
    event and, for record changes, a change-log row in the same transaction (`Audit/AuditTrail.cs`, called by
    `IdentityDb.RaiseAsync` and `AccessDb.RaiseAsync`); each sign-in attempt is a security event (`IdentityDb.LogAttemptAsync`).
  - Database functions (`security definer`, owner login, fixed `search_path`; `app_rw` EXECUTE only): `aud.append_changes`,

    `tools/Erp.CodeGen/rules.yaml` `functions`).
  - Hash chain: one chain per customer, advisory lock, strictly increasing `occurred_at` (P2), daily anchors. Verifier
    (`Audit/ChainVerifier.cs`) rebuilds the canonical text in the application; API `POST /api/aud/verify`, migrator
    `audit verify`. Control-plane anchor copies `cp.audit_anchors` (CR-027), migrator `audit anchors-publish` (P5).
  - Per-person keys: `personal`/`restricted` values encrypted with the person's key (wrapped by the customer field key),
    salary with the customer key, `enc`/`hmac` columns recorded as changed only. `SubjectKeyService.DestroyAsync` erases.
  - Access log: generated reads write one `aud.access_log` row when salary, personal or restricted fields are shown
    unmasked (`GeneratedEndpointSupport.ShapeAsync`, `ISensitiveAccessLog`); history views with decrypted personal values
    and every export are logged too.

    `/export` (CSV, 10,000 rows), `POST /api/aud/verify`. Permissions `aud.*` (Q10) in the kernel baseline roles;
    `aud.history.view` on every baseline role. Texts `Erp.Kernel.Contracts/Audit/Localization/audit.{en,ur}.json`.
