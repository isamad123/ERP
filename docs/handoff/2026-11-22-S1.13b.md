## Found while building
- On the real access engine approving a setting change needs `cfg.setting_values.update` as well as the approver permission (S1.06 rule);
  the approvals browser scenario now gives its checker that permission.
- The control server of the browser tests must be a real person with the Tenant Admin role, not the system user.
- Long permission codes and seven-column tables overflowed phones and tablets: cells wrap anywhere and wide tables become cards below 1024 pixels.
- Business Users hold `iam.delegations.read` (their own), so the admin Delegations menu entry needs `iam.users.read` instead.
