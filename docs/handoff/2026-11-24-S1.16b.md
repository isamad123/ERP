# 2026-11-24 S1.16b export engine, export centre, export from every list (Build items 6 to 8)
Model: Sonnet 5.5, medium effort (slice Model line). Standing rulings CR-082 and CR-083. No fresh review required for this part (slice Q0: only part a).

## Built (3 lines)
Any list that has an `IExportRowReader` is exported as CSV or Excel by a background job that runs as the person who asked and reads the list through its own filter, sort, search, data scope and field security; the generator emits a reader for every generated table (kernel and HR), the audit search and the user list have hand-written ones.
A reason is asked when a salary, personal or restricted column is in the file; with `itg.export.requires_approval` on, such an export, or one above `itg.export.approval_rows`, waits for a second person through the existing approvals inbox; the file carries a watermark line and neutralised formula cells, is kept `itg.export.keep_days`, and only its maker downloads it.
Web: a lazy Export dialog on every generated list (`canExport`), the user list and the audit search, and the export centre `/admin/exports`; exports work when the customer is read-only or locked.
