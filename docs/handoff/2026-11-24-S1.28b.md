## Built
Each holiday shows its Hijri date (Umm al-Qura, company correction -1/0/+1, display only). Optional holidays: table `hrm.optional_holiday_choices`, a yearly limit (no default) and a cut-off, chosen through an API that self-service (S1.26) will reuse. Policy type `seasonal_timing` (Ramzan or any season by date range or Hijri month, new times or a percentage, break minutes) changes the day's times for the employee group the policy is assigned to, without touching the shift. `GET /api/hrm/shifts/effective?employment=&date=` answers published roster, else weekly-off policy, else holiday, else none, with the reasons. Screens: shifts (engine), roster grid (checks, assign, fill days, copy forward, publish, holiday header with Hijri), optional holidays with "shift of a day", Hijri column on the calendar screen.
