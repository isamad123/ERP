# Registers

| File | Holds | Changed by |
| --- | --- | --- |
| `requirements.csv` | Every requirement ID, phase, release tag (R in this release, L later, X not planned), slice, tests, status | Release tagging (approved by product owner); updated by each slice |
| `contracts.md` | Published module contracts and events with versions | Opus design sessions |
| `components.md` | Reusable components and patterns, owner, risk class | Build sessions |
| `dependencies.md` | Every third-party package, version and licence | Build sessions; licence must be permissive (D-09) |
| `risks-and-changes.md` | Open risks, overrides, deviations, change requests against baseline items | Any session raises; product owner closes |
