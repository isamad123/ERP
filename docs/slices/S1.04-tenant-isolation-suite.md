# S1.04 Tenant-isolation test suite
Class: B        Model: Opus 5.5 (high effort); fresh Opus session reviews the diff
Requirements: KRN-TEN-03, KRN-TEN-04; spec 03 section 10 invariant 10. Decisions: D-47.
Depends on: S1.03.

## Goal
An automated suite that tries to read and write another customer's data through every API endpoint, and fails the
build if any attempt succeeds. It runs on every push and grows automatically as endpoints are added.

## Build
1. Discover all endpoints from the API's endpoint metadata.
2. For each endpoint: create data in tenant A, call it as a user of tenant B with A's ids, A's host and B's token,
   and other crossed combinations; assert 403 or 404 and no data leak in the body.
3. Database-level check: the application role of tenant A's database cannot connect to tenant B's database.
4. Make the suite a required CI check.

## Acceptance
- Suite passes on the current endpoints.
- A deliberately broken endpoint (reading by id without the tenant connection) is caught; show the failure, then revert.
