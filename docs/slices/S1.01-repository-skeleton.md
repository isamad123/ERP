# S1.01 Repository skeleton, CI and guard rails
Class: A        Model: Opus 5.5 (high effort)
Requirements: none directly (enabling slice). Decisions: D-01, D-09, D-10, D-47.
Spec sections to read: `docs/architecture-reference.md` sections 3 and 6; `docs/specs/01-…` section 13 (repository layout) only.
Depends on: nothing.

## Goal
An empty but correct .NET 10 modular-monolith solution that builds and tests in GitHub Actions, with automated guard
rails that fail the build when rules are broken. No business features.

## Build
1. `global.json` pinning .NET 10 SDK; `Directory.Build.props` (nullable, warnings as errors, deterministic builds);
   `Directory.Packages.props` (central package versions); `.editorconfig`; `Erp.sln`.
2. Projects (empty, compiling):
   - `src/Host/Erp.Host.Api`, `src/Host/Erp.Host.Worker`, `src/Host/Erp.Host.Migrator`
   - `src/BuildingBlocks/Erp.BuildingBlocks.{Domain,Application,Infrastructure,Contracts}`
   - `src/Platform/Erp.Kernel.{Contracts,Domain,Application,Infrastructure,Api}` (one kernel module for 1.0)
   - `src/Modules/Hrm/Erp.Hrm.{Contracts,Domain,Application,Infrastructure,Api}`
   - `tools/Erp.CodeGen` (empty console project; filled in S1.02)
   - `tests/Erp.ArchitectureTests`, `tests/Erp.UnitTests`, `tests/Erp.IntegrationTests`
3. Architecture tests (NetArchTest or equivalent, permissive licence) that fail when:
   - a module project references another module's non-Contracts project;
   - Domain references Infrastructure or Api;
   - any code calls `DateTime.Now`, `DateTime.UtcNow` or `DateTimeOffset.Now` outside an `IClock` implementation;
   - any type or SQL text in a module contains a `tenant_id` column (D-47).
4. Integration test base using a real PostgreSQL 16 (Testcontainers, or the pre-installed local PostgreSQL service
   when Docker is unavailable), with one smoke test that connects and runs `select 1`.
5. GitHub Actions workflow `ci.yml` on push and pull request: restore, build, unit, architecture, integration tests
   (PostgreSQL service container), and a **licence gate** that lists all NuGet packages with licences and fails on any
   licence not in the allow list (MIT, Apache-2.0, BSD-2/3-Clause, ISC, PostgreSQL, Zlib, MS-PL only with a decision).
   Quiet output; upload full logs as an artifact.
6. Fill in the `## Commands` section of `CLAUDE.md` with the exact build, test and run commands.
7. Record every package added in `docs/registers/dependencies.md`.

## Acceptance
- `dotnet build` and `dotnet test` pass locally in the session and in GitHub Actions.
- A deliberately violating change (for example a `DateTime.UtcNow` call in a module) makes the architecture tests fail;
  show the failing output, then remove the violation.
- The licence gate passes and prints the package list.

## Out of scope
Database schemas, the code generator, any HTTP endpoint beyond a health check, the web client.
